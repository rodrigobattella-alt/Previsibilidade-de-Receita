# 04 — Gestão de pessoas

**Objetivo:** tornar a gestão de pessoas sistemática, previsível e intencional.

## Ações
- Estabelecer 1:1 quinzenal com liderados diretos.
- Realizar feedback mensal estruturado.
- Fazer conversa de carreira trimestral.
- Criar PDI para cada liderado.
- Registrar compromissos e acompanhar evolução.

## Indicadores
- ≥90% dos 1:1 realizados
- 100% dos liderados com PDI
- Feedbacks realizados no ciclo
- Evolução de clima
- Percepção do time sobre qualidade da gestão
