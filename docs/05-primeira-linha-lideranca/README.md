# 05 — Primeira linha de liderança

**Objetivo:** aumentar autonomia, accountability e capacidade decisória dos líderes.

## Ações
- Mapear decisões atualmente centralizadas.
- Definir decision rights por líder.
- Delegar explicitamente decisões operacionais.
- Fazer coaching em situações reais.
- Avaliar mensalmente decisões escaladas.
- Reduzir progressivamente participação direta na operação.

## Indicadores
- % decisões tomadas sem escalonamento
- Nº de escalonamentos/mês
- Performance dos líderes
- % reuniões operacionais delegadas
- % tempo dedicado à estratégia

> Preencher: qual comportamento Rodrigo irá mudar para deixar de ser o principal resolvedor?
