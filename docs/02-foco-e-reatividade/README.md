# 02 — Foco e menor reatividade

**Objetivo:** aumentar consistência e disciplina na execução da estratégia.

## Ações
- Definir 3 prioridades trimestrais.
- Criar critérios para entrada de novas demandas.
- Explicitar o que será despriorizado quando uma nova prioridade entrar.
- Criar ritual semanal de prioridades e impedimentos.
- Registrar decisões estratégicas e trade-offs.

## Indicadores
- Nº de pivots/trimestre
- % capacidade dedicada às prioridades
- Nº de iniciativas interrompidas
- Redução de retrabalho
- Clareza de prioridades percebida pelo time
